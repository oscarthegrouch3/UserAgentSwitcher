# UserAgent Switcher for Firefox

A lightweight, modern Firefox extension (Manifest V3) to quickly switch and spoof your browser User-Agent and platform.

- **Platform Presets**: Seamlessly switch between Windows, macOS, Linux, iOS (iPhone/iPad), and Android.
- **Full Spoofing**: Modifies both outgoing HTTP request headers (`webRequestBlocking`) and in-page JavaScript DOM properties (`navigator.userAgent`, `navigator.appVersion`, `navigator.platform`).
- **Clean Minimalist UI**: Simple platform and browser dropdowns with live status preview.
- **Zero Overhead**: Zero external dependencies. Starts disabled by default with 1-click reset to native Firefox.
